# Bug Reports And Contributions

This repository currently exists for official compiled Reforge beta downloads, end-user information, legal documents, and app bug tracking.

## Reporting App Bugs

App bug reports are welcome. Use the [Reforge app bug form](https://github.com/gonzoinc/reforge/issues/new?template=bug-report.yml), search for an existing report first, and provide enough detail for someone else to reproduce the problem.

Reports in this repository should cover the Reforge Windows desktop application only. Firmware, electronics, wiring, physical-display installation, vehicle behavior, and unrelated feature requests are outside its current issue scope.

Do not include passwords, access tokens, private keys, personal information, proprietary files, or other secrets in an issue, log, screenshot, or attachment.

## Code Contributions

Application source code is not published in this repository, and code pull requests are not currently accepted. Opening an issue does not grant access to private source or development material.

Documentation corrections may be proposed through an issue. Contribution policies may be expanded if the project publishes additional materials later.

## Submitted Material

Only submit text, screenshots, logs, and other material that you created or have permission to share. By submitting material to a public issue, you permit the project owner to reproduce, quote, adapt, and use it to investigate, document, and correct the reported problem.
